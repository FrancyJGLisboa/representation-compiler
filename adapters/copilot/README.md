# GitHub Copilot CLI adapter

Install the canonical Agent Skill directly from this public repository:

```bash
copilot skill add https://github.com/FrancyJGLisboa/representation-compiler/tree/main/skills/representation-compiler
```

Then use it in Copilot CLI:

```text
Use the /representation-compiler skill to help me understand this material:
[paste a transcript, URL, PDF, or notes]
```

If Copilot is already running, use `/skills reload` after installation.
